# Q&A Chatbot with RAG (Gemini)

A retrieval-augmented generation (RAG) chatbot that answers questions about your own documents (PDF and Word). It extracts text, splits it into chunks, embeds them with Google Gemini, stores them in a local Chroma vector database, and uses Gemini to answer questions grounded in your files — **with source citations**.

---

## Features

- **Multi-format ingestion** — `.pdf` (via `PyPDFLoader`) and `.docx` (via `Docx2txtLoader`)
- **Semantic search** — Gemini embeddings + Chroma vector store
- **Grounded answers** — the LLM answers *only* from retrieved context, refusing when the answer isn't in the documents
- **Source citations** — each answer reports which file (and page, for PDFs) it came from
- **Rate-limit safe** — batched embedding calls respect Gemini free-tier quotas
- **Persisted index** — embed once, query many times; no re-embedding per question
